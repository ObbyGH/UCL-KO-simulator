UCL KO simulator READ ME
========================
Plays out a UEFA Champions League Knock Out stage bracket. Includes 16 different teams.

Event order:
1. Create a 16 team bracket.
2. Play out the bracket:
	- 1. display matches.
	- 2. play first leg matches.
	- 3. play second leg matches and calculate aggregate scores.
	- 4. update the bracket according to the winners.
	- 5. repeat until winner.
3. Announce the winner.

Potential future updates:
- Show team stats at the end (e.g. top 5 highest scoring teams).
- tracking teams' paths to the final.
- a visual display for the bracket.
- a reset function.
